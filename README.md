# TCG Radar

Small, dependency-free dashboard for watching Pokémon TCG booster bundles and
Elite Trainer Boxes (ETBs) available from Czech retailers.

Open `index.html` in a browser. The demo catalog is intentionally kept in
`app.js`, where it can be replaced by data from a scraper or API later. Search,
stock/type filters, sorting, watched products, and target prices work locally in
the browser; tracking preferences are stored in `localStorage`.
